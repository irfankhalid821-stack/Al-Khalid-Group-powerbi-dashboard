# 📊 Al Khalid Group – Power BI Sales & Business Performance Dashboard

## 📌 Project Overview

This project presents an **interactive Power BI-style Sales & Business Performance Dashboard** developed for **Al Khalid Group**.

The purpose of this project is to transform raw sales transaction data into meaningful business insights through **data cleaning, KPI analysis, data visualisation, and interactive filtering**.

The dashboard provides a clear overview of sales performance, product performance, category performance, brand performance, discounts, quantities sold, and sales trends over time.

This project demonstrates practical skills in:

* Power BI Dashboard Development
* Microsoft Excel
* Data Cleaning
* Data Visualisation

* Sales & Revenue Analysis
* Business Performance Analysis

## 💰 Revenue & Profit Analysis

The project calculates important financial measures using sales transaction data.

### Revenue

Revenue is calculated based on:

**Revenue = Quantity × Unit Price − Discount**

### Cost

Cost is calculated based on:

**Cost = Quantity × Unit Cost**

### Profit

Profit is calculated as:

**Profit = Revenue − Cost**

### Profit Margin

Profit margin is calculated as:

**Profit Margin = Profit ÷ Revenue × 100**

These calculations allow the dashboard to provide a better understanding of business profitability rather than focusing only on sales volume.

## 🗂️ Dataset

The dataset contains simulated sales transaction records covering approximately **three months**.

The dataset includes the following fields:

| Column        | Description                         |
| ------------- | ----------------------------------- |
| `Date`        | Date of the transaction             |
| `InvoiceNo`   | Unique invoice/transaction number   |
| `ProductID`   | Unique product identifier           |
| `ProductName` | Name of the product                 |
| `Category`    | Product category                    |
| `Brand`       | Product brand                       |
| `Quantity`    | Number of units sold                |
| `UnitPrice`   | Selling price per unit              |
| `UnitCost`    | Cost per unit                       |
| `Discount`    | Discount applied to the transaction |
